Quickly upload example codes to Otto!

Start using your HP Robots Otto right away by directly saving code

Make sure you have updated Firmware and Libraries!
  1. Plug your Otto to your computer via USB-Serial
  2. Click on the [Upload] button of the code you want
  3. Select "USB-Serial (COM#)"
  4. Click in [Connect] button
  5. Wait until "Upload done!" appears in the button
